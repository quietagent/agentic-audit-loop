# Round 1

Read GOAL.md first. In this round, build only `stats.js` and its tests. The command line (`cli.js`) and `sample.txt` are for a later round: do not build them yet.

Work on one function at a time, in the order of GOAL.md:

1. Add the function to `stats.js`.
2. Write its test file in `test/` (for example `test/countLines.test.js`), with at least two tests.
3. Run `node --test`, and fix what fails before you go on to the next function.

Do all eight functions this way. Do not write several functions before you run the tests.
