# DECISIONS

The loop writes this file from the human's answers to the auditor's questions. The auditor reads it every round.
"answered" means the human chose it. "assumed" means no answer came in time, so the auditor's recommended option was used. "open" means an overnight run left a MUST question for the human to answer later: nobody has answered it yet, so nothing that depends on it is built. The human can change any answer later.

## Round <n> (or Goal check), <YYYY-MM-DD>
- Q: <the question>
  A: <the answer> (answered)
